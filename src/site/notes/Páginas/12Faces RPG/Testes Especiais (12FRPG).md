#T #12FRPG #Páginas 

**Os Testes Especiais** são testes com regras adicionais ou relacionados com alguma mecânica.
# Teste de Pavor
---

| **Perícia**         | [[Páginas/12Faces RPG/Fichas/Perícias#Vontade (Mente)\|Vontade]] |
| ------------------- | ------------------------------------- |
| Passo Mínimo        | 0                                     |

Você tenta ao máximo controlar seus sentimentos negativos impulsionados pelo medo. O teste de pavor é realizado toda rodada enquanto estiver [[Páginas/12Faces RPG/Condições (12FRPG)\|Condições]]. Basicamente, você rola um D6 antes de fazer qualquer ação durante a cena, o resultado define uma das consequências a baixo.
## Consequências de Pavor

| Valor | Consequência                                      |
| ----- | ------------------------------------------------- |
| 1     | Apavorado                                         |
| 2     | Anula o Dado de Perícia                           |
| 3     | Aplica desvantagem 2                              |
| 4     | Aplica Dano Mental (-1d4 PD)                      |
| 5     | Fica [[Páginas/12Faces RPG/Condições (12FRPG)#Paralisia\|Paralisado]] |
| 6     | Fim do Pavor                                      |

# Teste de Pilotagem (Navegação)
---

| **Perícia**          | [[Páginas/12Faces RPG/Fichas/Perícias#Agilidade (Reflexo)\|Agilidade]] |
| -------------------- | ------------------------------------------- |
| Passo Mínimo         | D6                                          |
| Dificuldade do Teste | Média (11)<br>                              |
| DT Acumulativa       | 11+2p/Rodada                                |

Você sabe operar veículos terrestres, aquáticos e aéreos, desde carros e motos até embarcações, aviões e helicópteros. Essa perícia mede seus reflexos, noção espacial e controle mecânico sob pressão.
